## Discovery

Accepted partial: **TaL Corpus (UltraSuite)**. Authoritative repository documentation states that spontaneous utterances can run to 60 s and that shorter segments (typically 5–10 s) were **manually annotated**; the annotation is distributed as CSV with start/end time in seconds and transcription. The corpus provides synchronized waveform, ultrasound (`.ult` + `.param`), synchronization waveform, lip video, and prompt metadata. This is a high-value articulatory-production source.

Repository: https://ultrasuite.github.io/data/tal_corpus/

Admission boundary: only the explicitly manual short-segment CSV layer is presently admitted. No automatic phone/word tiers are promoted without separate human-verification evidence. Bulk TaL1/TaL80 media are reference-only pending manifests/checksums because the repository warns that downloads are approximately 49 GB and 498 GB respectively.

Screened discovery: MRPL2 remains scientifically admissible but file-restricted; L2-ARCTIC remains a priority for its 3,599 manually examined utterances and error annotations; IFCASL remains high priority because >50% of phone/word segmentation was manually corrected, but an isolatable publicly downloadable corrected subset still needs resolution. RescueSpeech is a promising manually annotated primary German production corpus, but the surfaced metadata does not yet establish phonetic interval/landmark granularity, so it was not promoted in this pass. Nonspeech7k and non-human F0 benchmark material were excluded by scope.
