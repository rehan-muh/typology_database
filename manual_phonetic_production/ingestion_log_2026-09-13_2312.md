## Fresh discovery / repository inspection

### AUSpeech — Audio-Ultrasound Synchronized Tongue Movement Database for Mandarin speech

Decision: HIGH REVIEW, not core-promoted.

Authoritative project documentation reports synchronized `.wav` audio, ultrasound `.dcm`, `.lab`, and `.TextGrid` annotations from 54 participants (43 healthy, 11 with dysarthria). Normal-subject alignment is described as MFA followed by manual labeling checks for verification; patient pronunciation labeling is described as manual. This makes at least some layers potentially eligible under the human-created/human-verified criterion, but the precise file/tier-level verification scope remains unresolved.

Direct repository enumeration found four public example artifacts for `speaker00042_F_s1_stn00021`: TextGrid (412 B), LAB (8 B), WAV (80,622 B), and DICOM (99,820,856 B). Their Git blob hashes and authoritative URLs are recorded in `data/source_faithful/auspeech_mandarin_review_file_manifest.csv`; binary WAV/DICOM data were not mirrored.

The public TextGrid was directly parsed. It contains one interval tier named `words`, spans 0.0–2.51806 s, and has three intervals; the only labeled interval is `yu1` from 0.79 to 0.80 s. This annotation has **not** been admitted to core because the documentation does not yet prove that this specific example tier/file received exhaustive human verification. The 8-byte LAB file did not decode reliably in the surfaced representation, so no value was inferred.
