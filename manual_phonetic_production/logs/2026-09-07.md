## New accepted sources

### tang_parrell_niziolek_2022_variability
- Publication: Tang, Parrell & Niziolek (2022), *Movement variability can be modulated in speech production*, Journal of Neurophysiology, DOI 10.1152/jn.00095.2022.
- Public data/code: OSF `stjc9`; associated analysis utilities in `carrien/free-speech` (MIT-licensed code repository).
- Primary production: 87 native American-English speakers across four experiments (N=24,22,21,20).
- Task: repeated productions of three vowel words under real-time F1/F2 auditory-feedback perturbations.
- Manual provenance: all trials checked manually for production errors; vowel onset/offset first detected with participant-specific amplitude thresholds, with erroneous automatically defined landmarks manually corrected using waveform and spectrogram.
- Documented measures/predictors entered into a paper-level variable dictionary pending file-level parse: F1, F2, vowel onset/offset, production-error status, word/vowel, experiment, phase, perturbation type/magnitude and trial index.
- Status: ACCEPTED_REFERENCE_LAYER; deep OSF file/table inventory is next. Do not assume OSF public access grants redistribution rights.
