# 2026-09-06 F1/F2 vowel-coarticulation crawl

## Newly accepted

### `yazawa_kondo_2019_japanese_vowels`

- Repository: https://zenodo.org/records/15227304
- Publication: https://www.internationalphoneticassociation.org/icphs-proceedings/ICPhS2019/papers/ICPhS_720.pdf
- DOI: 10.5281/zenodo.15227304
- Language: Tokyo Japanese (`japa1256`)
- Speakers: 16 (8 female, 8 male in the source description)
- Scale: 3,200 target-vowel tokens
- Design: controlled `/C1V1C2V2/` nonce words, isolation and carrier-sentence conditions
- Acoustic data: F1/F2 midpoint plus 30 equally spaced F1/F2 samples over the central 20–80% of V1
- Provenance: vowel boundaries first proposed by SPPAS and then manually modified in Praat to the first/last positive zero crossings for every analyzed token
- Decision: `INCLUDE_MEASUREMENTS`
- Primary use: C→V F1/F2 magnitude and temporal extent; transconsonantal anticipatory V→V; following-consonant contextual effects. Phrasal condition can be a flexibility moderator.
- Raw audio is not part of the current Zenodo release, so no new acoustic re-extraction is assumed.

## Backlog conversion

Added `scripts/canonicalize_cohn_f1f2.py` for the released Cohn–Zellou table. A local conversion of the harvested OSF table produced:

- 2,362 usable target-vowel tokens
- 27 speakers
- 23,620 original F1/F2 trajectory rows
- five documented retained vowel windows centered at 0.2145, 0.3575, 0.5005, 0.6435, 0.7865

The source paper states that formants were measured over seven normalized windows and that endpoint windows were omitted; the retained windows cover 14.3–85.8% of the vowel. The converter preserves source word, vowel, structure, style and demographic labels and deliberately leaves canonical IPA blank where the released analysis table does not itself establish it.

Local referential-integrity checks passed: token IDs were unique, speaker IDs were correctly namespaced, measures were only `F1_HZ`/`F2_HZ`, all normalized times were within [0,1], and every trajectory referenced a known token. The committed converter invokes `scripts/validate_coarticulation.py` whenever run inside the repository.

## Schema correction

Updated `docs/coarticulation_schema.md` so the subtree now explicitly targets vowel F1/F2 coarticulation only. Magnitude, temporal extent and flexibility are the core estimands. Duration, F0, VOT, nasality-specific measures, CPP, spectral tilt and other measures are metadata/covariates rather than target outcomes.
