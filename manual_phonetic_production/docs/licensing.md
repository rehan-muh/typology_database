# Licensing policy

Repository discovery does not imply redistribution permission.

- Preserve the source license on every dataset and derived row.
- Do not commit restricted raw audio.
- Do not mirror large audio bundles unless the source license clearly permits redistribution and there is a scientific reason to do so.
- Prefer source URLs + checksums + reproducible download scripts.
- For mixed-license collections, split derived outputs by source license where necessary.
- Human-participant metadata are limited to variables explicitly released by the source; do not infer sensitive attributes.
