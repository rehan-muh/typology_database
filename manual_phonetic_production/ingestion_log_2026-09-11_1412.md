## Discovery pass

### AUSpeech — added to REVIEW

Added `auspeech_2025` to the high-priority review increment. The Scientific Data release describes a public ~676 GB primary Mandarin production dataset with **54 participants (43 healthy, 11 dysarthric)** and approximately **22.31 hours** of synchronized audio and ultrasound. Annotation files are supplied as `.lab` and `.TextGrid`.

The accompanying project documentation states that normal-speaker MFA alignment was followed by **manual labeling checks for verification**, while patient speech used **manual pronunciation annotation**. This makes an isolable human-verified/manual layer potentially eligible for the core database. Because the archive is extremely large and this pass did not yet enumerate/download the ScienceDB hierarchy with stable file-level checksums and license metadata, it remains REVIEW rather than being admitted prematurely. Next action is archive enumeration and isolation of the manually verified/manual annotation layers; any unverified automatic alignment must remain excluded.

### SAIT-EMA — screened, not admitted

The 2026 SAIT-EMA dataset is a strong articulatory resource (18 participants; AG501 3-D EMA at 250 Hz with synchronized 48-kHz audio). The authors manually screened and removed misaligned/unintentional-repetition tokens, but its released syllable/initial/final TextGrids are generated automatically with MFA. The paper explicitly warns that these alignments may have temporal offsets and recommends manual verification/refinement for high-precision timing. Therefore the automatic interval layer does **not** satisfy this database's manual-annotation criterion as released. No core or REVIEW row was added solely for those automatic TextGrids. A future ingest could consider raw instrumental EMA observations only if the provenance/selection layer is represented without treating automatic boundaries as manually verified phonetic annotations.
