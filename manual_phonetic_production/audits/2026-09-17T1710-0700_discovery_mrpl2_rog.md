## MRPL2 — Multimedia Russian–French Learner Corpus, second edition

**Decision:** REVIEW — high priority for file-level enumeration and annotation ingestion.

**Why it is relevant:** MRPL2 is a primary learner-production corpus built around Russian L1 / French L2 speech. Public descriptions identify aligned speech and multimodal annotation resources, including phonetic/prosodic material. This is directly in scope if the deposited segment/prosodic tiers can be verified as manually created, manually corrected, or exhaustively human-verified.

**Guardrail:** do not admit automatically aligned phone/word intervals merely because they coexist with human annotation. At ingest, inventory every annotation tier separately and assign annotation provenance per tier. Preserve orthographic, phonetic, prosodic, gesture, task, learner, and recording metadata source-faithfully. If a tier's provenance is not explicit, retain it in review rather than core.

**Next actions:** resolve authoritative repository/package; enumerate all files; identify TextGrid/EAF/annotation tables; inspect README/methods for tier-specific provenance; checksum public annotation objects; parse manual/manual-corrected tiers to source-faithful interval/landmark tables; namespace speaker/recording/token IDs.

## ROG / Roots of Gestures corpus

**Decision:** REVIEW — potentially admissible only for isolatable new manual production annotations.

**Why it is relevant:** the corpus/repository literature describes French/German speech with manual prosodic annotation and gesture annotation. This can qualify under the database rule allowing secondary recordings only when a new, genuinely manual annotation layer is contributed and can be isolated.

**Lineage risk:** some underlying recordings derive from pre-existing corpora. Therefore the recording lineage must be resolved before any core admission. Never count reused recordings as new primary recordings. If manual prosodic/phonetic tiers are public and isolatable, ingest those annotations as a new annotation lineage linked to the original recording lineage.

**Next actions:** resolve public deposit; enumerate files; identify which recordings are original versus reused; inspect prosodic tier provenance and annotation scheme; ingest only isolatable human annotation layers; record parent recording dataset IDs and deduplicate at recording lineage level.

## Exclusion / ambiguity controls applied this pass

- Search hits describing only manual orthographic transcription were not treated as sufficient phonetic-production annotation without an explicit phonetic/prosodic/articulatory/voice-quality measurement layer.
- Corpora based on third-party media remain excluded even when manually segmented.
- Forced alignment, ASR transcription, automatic pitch/formant extraction, or automatic landmark detection alone do not qualify; they may be retained only when tied to a qualifying manual/manual-corrected layer and clearly marked automatic.
- Singing/music-production resources were excluded from consideration.
