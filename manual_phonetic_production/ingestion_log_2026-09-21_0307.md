## New discovery / review
### `friedrichs_etal_2026_multimodal_ema_eeg` — REVIEW
- Friedrichs et al. (2026), *A multimodal speech-production dataset with time-aligned articulography, EEG, audio, and vocal-tract anatomy*, Scientific Data 13:1243. Public dataset release DOI: `10.48656/vc7s-pt02`; canonical family DOI `10.48656/6y1s-px92`; CC-BY 4.0.
- Primary, non-singing German production from 29 adult native speakers.
- Public documentation reports ~17 h EMA at 1250 Hz, 48-kHz audio where available, 64-channel EEG for DDK tasks, 8,700 DDK syllable-task trials, passage reading, sustained vowels, palate tracing, pharyngometry/rhinometry, craniofacial anthropometry, 3D head meshes, and machine-readable event/session metadata.
- Crucially for future broad ingestion, the deposit preserves native-rate EMA coordinates (rather than only summaries), raw/pre-normalisation positions, head-corrected positions, per-coil diagnostics, equipment/acquisition metadata, anatomy measurements, event codes, session indices, demographics/modality flags, and Praat TextGrids paired with prompt-response WAVs.
- The article states that TextGrids mark visible cue onset and response onsets, but the documentation inspected in this run did **not** explicitly establish whether those landmarks were manually created, manually corrected, or exhaustively human-verified. Therefore this source is retained in REVIEW and no observations are admitted to core yet.
- If manual provenance is verified, ingest broadly: every TextGrid interval/point; all 1250-Hz EMA samples with original coordinates and separate normalized/head-corrected values; DDK task/rate/voicing/place conditions; sustained-vowel and passage metadata; participant metadata; pharyngometry/rhinometry area-distance profiles; anthropometry; palate traces; event/session maps; equipment; file manifest/checksums; and provenance. Do not commit raw WAV/BDF/large meshes to GitHub.
