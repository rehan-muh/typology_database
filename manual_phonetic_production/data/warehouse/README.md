# Manually Grounded Phonetic Production Warehouse

This directory is the **analysis-agnostic ingestion layer** for the manually annotated phonetic production project. It sits upstream of `data/coarticulation/` and must not be restricted to any one analysis.

## Core rule

Admit primary, non-singing production observations only when the relevant annotations, intervals, landmarks, labels, or measurements were manually created, manually corrected, or exhaustively human-verified. Automatically aligned material may be retained only for the explicitly human-corrected subset. Do not silently promote an automatically aligned surrounding phone tier to manual status merely because target segments were corrected.

## Preservation policy

For every source, preserve original variable names and values before harmonization. Unknown/source-specific variables are retained rather than discarded. Standardized values are added as new fields/views and never overwrite source values. IDs are namespaced (`source_id::source_id_within_dataset`). Do not invent IPA, context, demographic values, or measurement units that the source does not establish.

## Files

- `source_table_variable_inventory.csv`: table-level inventory of parsed source tables, row/column counts, and all original variables found in each table.
- `file_manifest.csv`: generated by `scripts/build_phonetic_warehouse.py`; repository file inventory and immutable references/checksums where available.
- `table_inventory.csv`: generated table-level checksums and counts.
- `variable_dictionary.csv`: generated one-row-per-source-variable dictionary including domain, units/time window when defensible, datatype, example coding, missingness, manual annotation method, provenance, and notes.
- `ingestion_status.csv`: generated source-level coverage and pending-work summary.
- `harmonized/`: linked cross-source tables added only when mappings are defensible.
- `source_faithful/`: source-level observations only when redistribution is explicitly permitted.

## Licensing

**Publicly downloadable does not mean licensed for republication.** If a deposit's redistribution terms have not been verified, the warehouse stores its authoritative URI, file/table schema, counts, checksums, variable dictionary, and reproducible ingest logic rather than mirroring the data into GitHub. Raw audio is not mirrored merely because it is downloadable.

PAVOQUE is currently an example of an explicitly licensed source (CC-BY-NC-SA-4.0). Its parsed manually corrected phone observations can be reproduced from the repository YAML with the existing PAVOQUE scripts. Large binary/source-faithful outputs should not be described as committed until repository transfer has actually occurred.

## Current parsed staging coverage (2026-09-06)

The audit staging layer contains 49 parsed source tables plus the PAVOQUE segment table, totaling **419,230 parsed rows** and **659 source-variable records** across Cohn-Zellou, Cox et al. Danish IDS, Chaturvedi-Shaw, Mitra-Dutta, SwehVd, and PAVOQUE. Additional accepted sources remain at manifest/re-extraction stages.

Run:

```bash
python manual_phonetic_production/scripts/build_phonetic_warehouse.py --audit-dir audit_output
```

after a fresh `audit_open_data.py` harvest to regenerate the full manifests/dictionaries. The coarticulation tables remain derived views, not the master storage model.
